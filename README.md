# HomeWork_TASKER
# 📚 Таскер домашних заданий
## 📝 Пример использования

1. Откройте `tasker.html`.
2. Введите никнейм (например, `Student1`) и пароль (`12345`) → **Зарегистрироваться**.
3. Нажмите **➕ Добавить задание**, заполните поля:
   - Название: «Решить задачи №10-20»
   - Предмет: «Математика»
   - Дедлайн: выберите дату и время
   - Время на выполнение: 30 минут
4. Запустите таймер (▶) и приступайте к работе.
5. Если затянете — появится уведомление, что время превышено.
6. По завершении нажмите **🏁 Завершить**, введите оценку, и задание перейдёт в статус завершённых.

## 🤝 Вклад в проект

Проект создавался как учебная работа, но вы можете предлагать улучшения через Issues и Pull Requests. Идеи:
- Поддержка нескольких языков;
- Экспорт задач в файл;
- Группировка задач по предметам или дедлайнам;
- Анимация таймера или звуковые оповещения.
